Channel Monitor

A personal, self-hosted dashboard for monitoring the performance of the YouTube channels I own.

What it does

  • Collects public statistics for my channels (subscribers, video views, likes, comments).
  • With my explicit authorization, reads read-only YouTube Analytics data for my own channels (watch time, views by content type, traffic sources, audience geography).
  • Displays everything in a local dashboard that runs only on my own computer.

Who it is for

This is a private tool used only by its developer to view analytics for channels the developer owns. It is not offered to the public and has no user accounts.
