Privacy Policy — Channel Monitor

Effective date: November 19, 2026

Channel Monitor ("the app") is a personal tool that runs locally on its developer's own computer. It is used only by its developer to view analytics for YouTube channels the developer owns.

Data the app accesses

When the channel owner explicitly authorizes the app through Google OAuth, it requests these read-only scopes:

  • youtube.readonly: to identify the authorized channel and read its public video list.
  • yt-analytics.readonly: to read aggregated channel analytics such as views, watch time, average view duration, subscriber changes, traffic sources and audience countries.

The app cannot upload, edit, delete or comment on anything, and it never accesses passwords, emails, payment information or any data outside these scopes.

How data is used

Data is used only to display performance statistics in the developer's local dashboard. It is not used for advertising, not sold, and not shared with or transferred to any third party.

Storage and security

All data, including OAuth tokens, is stored only on the developer's own computer. No data is sent to any server other than Google's own APIs.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at Google Account → Third-party connections. Deleting the app's local data folder removes all stored data and tokens.

Contact

Questions about this policy can be raised through the GitHub repository that hosts this page.
